Important notes:
- This application should be entirely layer 7, meaning there is no need for a web server. It can be just html, js and css and I will just utilize the browser to open those files on my local machine. 
- Data can be saved to my file structure in .json format and there should be a load button and save buttons at the top. 
- The exercises should be kept track of with meta data for how often they're skipped or chosen, when I view the exercise library page I can organize by most popular exercises.

Code structure (see README "Development"):
- The source is TypeScript in src/. app.js is generated by `npm run build` (or `npm run dev`); never edit app.js by hand, and commit the rebuilt app.js with source changes. The built output must stay plain html, js and css that works from file:// (no ES modules or server at runtime).
- Each user action is an interactor in src/interactors/<area>/<use-case>.ts with an "As a user / When / Then" comment. Interactors take (gateways, input), change data only through gateways, return an InteractorResult, and never touch the DOM.
- Gateways (src/gateways/gateways.ts) are the only way to reach data: the saved document, browser storage, the JSON file, the clock and randomness.
- The JSON file is only written when the user presses Save; the browser copy is updated after every change.
- Run `npm test` before finishing a change.
