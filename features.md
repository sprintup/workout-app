As a user
When I open the app
Then I see 5 tabs for monday-friday with 3 sets of 2-3 exercises that are randomly generated from the exercise library. They should be selected in a way that maximizes training variation without crossing over into muscle groups which are not the target of that days training. 

As a user
When I workout
Then I can add a checkmark next to each exercise circuit (not individual exercise) to count going through the circuit 3 times. 

As a user
When I view an exercise
Then I can see a link to a demo of the exercise as well as be able to see the load and reps for that exercise, which are saved in json

As a user 
When I finish a week of training
Then I can press a button to start a new week with blank checkmarks

As a user
When if I want to replace an exercise in one of the spaces 
Then I can simply change out that exercise from the library.
